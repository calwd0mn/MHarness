# Proposal

## Why

侧栏从浏览器本地目录读取会话 ID，可能显示另一套后端的会话，也让无痕窗口无法发现当前后端已保存的历史。连接同一后端的窗口需要共享会话目录，同时在打开期间各自维护选中项。刷新时以同一站点最后保存的选择作为恢复提示。

## What Changes

- 提供 `GET /api/sessions` 和独立目录 SSE。启动和重连时获取以已提交会话清单为准的完整目录基线，再按快照标明的 SSE 进度合并实时通知。列表查询可补齐持久化会话和纠正本窗口的摘要，不触发实时广播。
- 目录摘要包含创建时间、活动时间、空会话状态和当前运行状态。侧栏按活动时间排序，仅显示本窗口选中的空会话。
- 会话注册后即可广播新增。确认首次创建失败时携带原因撤回条目。首次 `turn/start` 使空会话在其他窗口的侧栏中可见。
- 浏览器通过共享的 `localStorage` 键保存会话选中提示。无有效选择时主区域保持空白，打开会话仍通过现有 follow 快照恢复聊天历史。

## Impact

- 事件会话应用、会话创建及 Agent 生命周期、共享 HTTP 与 SSE 契约，以及 Web 目录状态和侧栏。
- 首版采用单实例、单目录。开发与生产由各自 SQLite 路径隔离。
- 本地 Web 开发入口默认通过 HTTPS 协商 HTTP/2，避免多标签页的两类长订阅占满 HTTP/1.1 连接池。
- 多用户授权、会话删除和归档、手动排序、聊天历史分页及 follow 游标续订留待后续。
