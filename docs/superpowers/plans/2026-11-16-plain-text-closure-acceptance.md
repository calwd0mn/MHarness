## 验收条件

1. 路由替身测试与正式集成均符合 2.9 的请求、状态码及响应。重复编号优先确认，忙碌拒绝不占用新编号，未加载取消不触发加载，维护任务取消转发到当前占用。
2. 真实 SSE 首帧快照失败只交付一个安全终止错误。检查点失败阻止模型请求，原事件仍可跟随并恢复。持久历史保持已提交前缀，follow 展示已接受尾部，独立只读进程和重启不恢复未提交内容或续跑模型。
3. 草稿按 Attempt 和原始日志位置交接，任一先到只显示一个消息节点。错误引用、缺号、实时版本和范围错误进入有界恢复，旧回调不影响新会话。
4. 页面通过 HTTP 或本会话用户事件确认受理，丢失响应仍沿用原编号。首次打开、切回和重连用快照替换完整窗口。会话 A 生成途中切到 B，再切回 A，恢复已生成草稿并只形成一条正式回答。
5. 服务端终止错误保留画面并等待主动重试，执行错误不触发重连。异步快照构建、失败及代次变化均不提交部分视图。恢复预算不会因创建新连接或新代次被重置。
6. 在实际工作区执行类型检查、服务端测试、Web 测试、Web 构建、差异空白检查和 OpenSpec 严格校验。逐条记录任务与验收证据，全部通过后才勾选对应任务。
