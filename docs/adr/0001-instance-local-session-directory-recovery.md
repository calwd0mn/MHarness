# 用实例内目录通知与全量快照恢复会话目录

同一后端实例的多个窗口需要同步会话目录，其中还包括已注册但首次提交结果待核实的会话。会话头和日志负责持久化，目录通知使用实例内版本。窗口先订阅通知，再读取完整目录快照，按快照覆盖的版本接续其后的通知。通知缺号、连接断开或实例重启时，窗口重新取得快照。

这一选择将恢复成本放在全量读取上，省去了持久化通知回放及其与会话提交的协调。版本的有效范围是当前实例。将来如果多个实例要共同提供一份目录，需要重新确定版本和通知的归属。
