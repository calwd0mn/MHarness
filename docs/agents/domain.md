# 领域文档

## 布局

采用单一领域布局：

- GLOSSARY.md：全项目共用术语。
- docs/adr/：跨变更保留的架构决策。

不因 workspace 包数量增加而自动拆分领域上下文。

## 阅读规则

- 探索相关业务前，读取已有 GLOSSARY.md 及相关 ADR。
- 若后续明确采用 GLOSSARY-MAP.md，按映射读取相关领域文档。
- 文件不存在时继续工作，不主动要求创建空文件。
- 术语或决策明确后，再通过相应领域建模流程维护文档。

## 一致性

- 输出中的业务概念沿用术语表定义，避免随意替换同义词。
- 遇到真实术语缺口时提出，不自行假定定义。
- 与现有 ADR 冲突时，明确指出冲突及重新讨论的理由。
- 当前变更设计与实施任务仍由 OpenSpec 维护；
  ADR 记录长期决策及理由，引用相关变更，
  不复制整份设计或任务清单。
