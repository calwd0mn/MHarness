# 问题分类状态

普通 issue 顶部的 `Status:` 使用以下映射：

| 技能角色 | 本地状态 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 描述完整，适合交给 Agent 处理 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不予处理 |

例如：Status: needs-triage

这些状态只表达分类结果，不替代 OpenSpec 任务勾选，
也不授予代码修改权限。

Wayfinder 子票据的工作状态遵循 issue-tracker.md。
